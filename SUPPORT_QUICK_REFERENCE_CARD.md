# Support System - Quick Reference Card
## One-page cheat sheet for solo founders

## THE SYSTEM IN 60 SECONDS

```
YOUR SUPPORT FLOW:

User → Searches KB (self-resolves 20%)
      → Asks Chatbot (resolves 60%)

Result: 80-90% automated, 2-3 hours/week from you
```

## TOP 25 SUPPORT QUESTIONS

### Form (40%)
- What if relationship changed?
- Does this help with RFEs?
- Can I use for next form?
- Is filled PDF acceptable?
- What documents needed?
- How to fill [field]?
- Co-sponsor rules?
- Name/accent handling?
- Save progress?
- Already started—help?

### Technical (30%)
- PDF won't download
- Form is slow
- Can't log in
- Answers not saving
- Doesn't work on phone
- Form keeps crashing
- Can't find KB
- Search not working
- Browser issues
- Server error

### Billing (15%)
- Why charged twice?
- Can't find download
- Bulk discount?
- Payment plan?
- Refund?
- Which payment methods?
- Invoice?
- Tax receipt?

### General (15%)
- Is it safe?
- Who runs this?
- Do you have lawyers?
- US only?
- Share with lawyer?
- Mistake after filing?
- What happens next?
- Case tracking?
- Legal advice?
- Status check?

## WHEN TO SCALE

### Stay Solo If:
✓ < 100 users
✓ < 10 emails/week
✓ > 75% automation
✓ You have time/energy

### Add Infrastructure If:
⚠️ 100-300 users
⚠️ 10-20 emails/week
⚠️ Automation < 75%
⚠️ You want to focus on product
→ Add Help Scout ($50/mo)

### Hire Contractor If:
🔴 300-600 users
🔴 20-30 emails/week
🔴 Support > 5 hrs/week
🔴 Need to focus on product
→ Hire 10 hrs/week @$150-300/week

### Hire Full-Time If:
🔴🔴 600+ users
🔴🔴 30+ emails/week
🔴🔴 Support > 10 hrs/week
→ Hire full-time $2,500-3,500/mo

## SUPPORT VOICE & TONE

Write like this:
- ✓ Clear (short sentences)
- ✓ Simple (6th grade English)
- ✓ Reassuring (normalize mistakes)
- ✓ Honest (admit what you don't know)
- ✓ Personal (sign your name)

**Example:**
```
Hi Sarah,

Great question! This is really common.

The answer is: [2-3 sentences max]

Check out: [Link to KB]

Still stuck? Reply here.

—
Your Name
Founder, [Tool]
```

## EMAIL PROCESSING RITUAL

### Friday 2:00pm (30 minutes)

1. **Open Gmail** (5 min)
   - Filter Support/New
   - Read all unread
   - Assign labels (Form/Tech/Billing)

2. **Quick responses** (10 min)
   - Simple Q → Copy/paste template
   - Add links → To KB articles
   - Send → Mark as done

3. **Complex responses** (10 min)
   - Personal Q → Write 2-3 sentences
   - Reference → Link to resources
   - Send → Mark as done

4. **Update database** (5 min)
   - Add to Notion
   - Track resolution time
   - Note patterns

## TEMPLATES TO CREATE

### Email Auto-Responder
```
Hi [Name],

Got your message! We reply within 24 hours.

Check our FAQ first: [KB link]

80% of questions are answered there.

If stuck, reply with:
- Issue type (form/tech/billing)
- What you tried
- Error message (if any)

Thanks,
[Your name]
```

### KB Article Template
```
Title: [Your Question]?

Short answer: [1 sentence]

Details: [2-3 sentences]

Steps (if applicable):
1. [Step 1]
2. [Step 2]
3. [Step 3]

Example: [Screenshot or example]

Related articles:
- [Link 1]
- [Link 2]
```

### Troubleshooting Template
```
Title: [Problem]

Symptoms: You see [error]

Cause: [Why this happens]

Fix (try in order):
1. [Step 1 with screenshot]
2. [Step 2]
3. [Step 3]

Still stuck?
Email: support@[domain]
Include:
- Screenshot
- Browser
- What you were doing
```

### Email Response Template
```
Hi [Name],

Great question!

[Answer in 2-3 sentences]

[Link to KB if relevant]

[Link to related resource]

Anything else?

[Your name]
```
